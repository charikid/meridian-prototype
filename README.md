# Meridian prototype

Clickable prototype of Meridian, an operational intelligence platform for asset-intensive operators: a Malaysia-wide view that drills into four missions (Telecommunications, Agriculture, Energy, Sustainability / Scope 3 freight).

- Single static page: `index.html`, no build step.
- Deployed on Netlify (`netlify.toml` publishes the repo root).
- Operational data is illustrative. Coastlines: Natural Earth. Freight emission factors: UK DESNZ 2025.
